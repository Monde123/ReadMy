# ReadMy — Change Log

## 2026-09-23 — Initial architecture

### Decisions

- Created the public `ReadMy` repository under `Monde123`.
- Defined ReadMy as a library of anonymized GitHub profile README templates and components.
- Established a content-first architecture with templates, components, assets, catalogs, examples, and documentation.
- Established anonymization rules for names, links, organizations, projects, statistics, and images.
- Established an image policy requiring meaningful alternative text and documented external services.
- Added the first reference template: `001-minimal-clean`.

### Next planned work

- Add reusable component examples.
- Add additional anonymized profile architectures.
- Expand the catalog of image and badge resources.
- Add templates until the collection reaches at least 50 designs.
- Add automated link and placeholder validation.
