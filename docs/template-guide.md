# ReadMy — Template Guide

## Required files

Every complete template should include:

```text
<template-id>/
├── README.md
├── metadata.yml
└── customization.md
```

## Metadata fields

At minimum, `metadata.yml` should define:

- `id`;
- `title`;
- `category`;
- `audience`;
- `style`;
- `sections`;
- `anonymized`;
- image policy fields.

## README requirements

A template must:

- use fictional data;
- include a clear role or positioning statement;
- group technologies logically;
- include at least one project or evidence section;
- provide neutral contact placeholders;
- avoid personal statistics;
- include accessible image markup when images are used.

## Customization requirements

Explain:

1. which values are fictional;
2. which links should be replaced;
3. which images are optional;
4. which external services are used;
5. which sections may be removed safely.

## Quality target

A template should be useful in two modes:

- **copy and customize** for beginners;
- **study and remix** for experienced users.
