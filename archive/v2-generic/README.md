# Gabarits génériques v2

Ces dossiers sont la copie des dix gabarits tels qu'ils étaient sur `main` au commit `93fc17d`, avant la galerie exploitable.

Ils partagent un seul squelette : bandeau, titre, « En bref », listes ou tableau, colophon. Seuls le thème, le bandeau et la liste de composants changent. Ils restent ici pour pouvoir revenir en arrière sans réécrire `main`.

Le catalogue actif est dans [`templates/`](../../templates). La décision est [D13](../../DECISIONS.md).
