# Contributing to ReadMy

Thank you for helping improve ReadMy.

## Before contributing

Read:

- [Architecture](docs/architecture.md)
- [Anonymization Policy](docs/anonymization-policy.md)
- [Image Policy](docs/image-policy.md)
- [Template Guide](docs/template-guide.md)

## New templates

A new template must include:

```text
<template-id>/
├── README.md
├── metadata.yml
└── customization.md
```

Use fictional identities, projects, links, organizations, and statistics. Do not copy personal data from a real profile.

## Naming

Use a three-digit prefix and a short kebab-case name, for example:

```text
014-terminal-creative
```

## Pull requests

Describe:

- the target audience;
- the design intention;
- the sections introduced;
- external services used;
- the anonymization checks performed;
- accessibility considerations.

Keep one design or focused change per pull request when possible.
