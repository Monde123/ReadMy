# Customization Guide: Top Secret Classified Dossier (Template 035)

Built for security researchers, reverse engineers, privacy advocates, infrastructure defenders, and developers who love espionage aesthetics and SCP Foundation style files.

---

## 1. Quick Customization (5 Minutes)

1. **Codename & Black-Bar Redactions**:
   - Replace `SPECTER NULL` with your handle, alias, or real name.
   - Use Unicode black boxes (`██████████`) to simulate classified, redacted text on sensitive details, secret locations, or previous stealth employers.
2. **Declassified Black-Projects**:
   - Reframe your major projects as "Classified Operations" with operational codenames (e.g. *OPERATION NIGHT-WATCH*, *PROJECT ZERO-LATENCY*).
3. **Interactive Redacted Memoranda**:
   - Edit the `<details><summary>` blocks to reveal funny anecdotes, war stories from production outages, or high-level architecture principles.
4. **Dead-Drop Box**:
   - Update the secure contact box with your PGP key, ProtonMail/anonymous email, and GitHub profile.

---

## 2. Visual Style

This template uses high-contrast typography, ASCII security borders, and redactions that look cinematic in GitHub Dark Mode while remaining completely legible in GitHub Light Mode.
