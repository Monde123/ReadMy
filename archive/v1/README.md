# Archive v1

Ce dossier conserve, sans modification de contenu, l'arbre ReadMy tel qu'il était sur `main` au commit `799047f` (26 septembre 2026), avant la reconstruction v2.

Il n'est pas le catalogue supporté. Les templates, composants, catalogues YAML et la skill historique restent ici pour pouvoir revenir en arrière : déplacer le dossier concerné vers la racine restaure le fichier d'origine.

Le catalogue actif est `templates/` à la racine de `rebuild/v2`. Les raisons du retrait de chaque modèle sont dans `DECISIONS.md` et `AUDIT.md`.
