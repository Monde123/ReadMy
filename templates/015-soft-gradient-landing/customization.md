# Customization Guide: Soft Gradient Landing Page

The `015-soft-gradient-landing` template structures your developer profile as a sleek SaaS product landing page designed to attract clients, consulting gigs, or high-value job opportunities.

## Quick Start (3 Steps)

1. **Hero & Value Proposition**:
   - Write a compelling value proposition headline (what outcome you deliver).
   - Adjust the 3 status pills at the top (Availability, Primary Competency, Core Stack).
   - Update the primary CTA links (e.g., `Schedule Strategy Call`, `View Live Portfolio`).

2. **3 Pillars & Shipped Products**:
   - Customize the 3-column value proposition table with your specific superpowers (e.g. Speed, Design System Rigor, Conversion Optimization).
   - Highlight 2 flagship software products with metrics (Users, ARR, Stars, or performance benchmarks).

3. **Collaboration Packages & Testimonial**:
   - Customize the Collaboration Tiers table with your actual services (e.g., Sprint, MVP build, Fractional Lead).
   - Add a genuine testimonial or recommendation from a colleague, manager, or client.

## Aesthetic & Tone

- Warm, confident, and commercial tone.
- Built with standard Markdown tables and Shields.io badges that work in dark and light modes.
