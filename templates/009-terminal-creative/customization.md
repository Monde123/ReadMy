# Customization Guide: Terminal Creative

The `009-terminal-creative` template transforms your profile README into an interactive Unix/Linux command-line terminal session.

## Quick Start (3 Steps)

1. **Terminal Hero (`fastfetch`)**:
   - Replace `jordan-smith` with your GitHub username or terminal handle.
   - Adjust the ASCII logo art or replace with your preferred distro logo or mascot.
   - Update your Shell, Uptime (years of coding), and primary languages.

2. **Terminal Experiments & Daemons**:
   - Each project card features a simulated CLI command invocation (e.g., `$ tinyserve --port 3000`).
   - Replace project names, short descriptions, and Shields.io badges.
   - Use the table layout to showcase 4 utilities side-by-side.

3. **Toolchain & Session Exit**:
   - Adjust the list of installed binaries in the table.
   - Customize the exit block (`curl`, `ping`, email address, and blog link).

## Theme Notes

- Designed to look authentic in both dark and light modes through native GFM code blocks and standard ASCII characters.
- Requires zero external image services; 100% resilient offline markdown.
