# Customization Guide: Cyberpunk Netrunner (Template 031)

This template is engineered for offensive security specialists, low-level Rust/C engineers, distributed systems developers, and cyber-aesthetic purists.

---

## 1. Fast Setup (5 Minutes)

1. **Header Alias & ASCII Title**:
   - Replace `ZERO_HEX` with your hacker handle or pseudonym.
   - You can replace the top ASCII banner with your own initials using standard FIGlet font "Slant" or "Standard".
2. **System Telemetry**:
   - Update the `[SYSTEM KERNEL]` key-value pairs with your actual hardware (e.g., M3 Max, Framework 16, NixOS, ThinkPad).
   - Adjust the ASCII progress bars (`MEMORY BUFFER LOAD`, etc.) to match your metrics or personal jokes.
3. **Missions / Exploits**:
   - Rename the missions `[MISSION 0x01]` to your real projects, CLI tools, or white-hat bounties.
   - Insert real technologies in `Tech Vector:`.

---

## 2. PGP & Communication Relay

Replace the PGP fingerprint in the bottom box with your real GPG public key ID:
```text
PGP FINGERPRINT : YOUR_GPG_KEY_ID_HERE
MATRIX COMMS    : @yourhandle:matrix.org
```

---

## 3. Dark/Light Theme Behavior

This template uses high-contrast monospace boxes and GitHub shields. It is optimized for Dark Mode (`#0d1117`), which gives the authentic glowing terminal look.
