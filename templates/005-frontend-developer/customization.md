# Customization Guide: Frontend Developer (Bento Grid)

The `005-frontend-developer` template organizes your personal brand around a modern **Bento UI architecture**.

## Quick Start (3 Steps)

1. **Header & Persona**:
   - Replace `Morgan Riley` with your name.
   - Adjust the title (`Staff Frontend Architect...`) and core paragraph.
   - Update the top Shields.io badges with your primary framework and city.

2. **Bento Grid Customization**:
   - **Cell 1 (Philosophy)**: Write 2–3 sentences on your interaction philosophy, accessibility tenets, and engineering focus.
   - **Cell 2 (Telemetry)**: Adjust the 4 KPI figures (e.g., replace `Lighthouse 100/100` with `Test Coverage`, `Bundle Budget`, or `Design Tokens Shipped`).
   - **Cell 3 (Interactive Primitive)**: Showcase your favorite UI component (e.g. Combobox, Modal, Virtualized Grid). Include code snippets inside the `<details>` accordion.
   - **Cell 4 (Toolchain)**: Swap or add shields badges for your preferred frontend libraries (Vue, Svelte, Tailwind, etc.).

3. **Projects & Contact**:
   - Update the 2 project cards inside the bottom table with links to your live web applications or component repositories.
   - Update the footer contact links.

## Theme & Accessibility Tips

- This layout uses native HTML `<table>` cells that render cleanly in both GitHub Dark (`#0d1117`) and GitHub Light (`#ffffff`).
- The `<details>` accordion requires zero JavaScript, allowing users to toggle technical details inline.
