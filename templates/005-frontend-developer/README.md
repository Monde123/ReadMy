<h2>Principles</h2>
<ul>
<li>Accessibility is not a feature: it is the fundamental medium of the open web.</li>
<li>Interaction latency above 50ms feels sluggish: prioritize input responsiveness over visual chrome.</li>
<li>Zero runtime styling overhead: tokens must resolve to static CSS custom properties.</li>
</ul>
