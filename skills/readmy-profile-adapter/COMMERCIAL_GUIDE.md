## 1. Executive Product Overview

### What is ReadMy Profile Adapter?
**ReadMy Profile Adapter** is a commercial-grade, multi-platform AI Skill designed to craft, audit, and maintain pristine, indestructible GitHub profile READMEs. 

Unlike generic profile generators that litter profiles with fragile third-party widgets (Shields badges that 404, sleeping Heroku dynos, rate-limited Vercel graphs, and visitor counters that break), ReadMy guarantees:
- **100% Uptime & Durability**: Every banner is a locally synthesized, zero-dependency SVG (< 20 KB).
- **Native Dual Theme**: Seamless automated switching between GitHub Dark Mode and Light Mode via HTML5 `<picture>` media queries.
- **Strict Anti-Hallucination Law**: Zero invented metrics, zero fabricated stars, zero made-up companies.
- **Instant Fragility Audit**: Live scanning of existing profiles with a 0–100 Durability Score and automated replacement suggestions.
- **Universal Portability**: Runs natively in **Google Antigravity**, **Cursor / Windsurf**, **Claude Code**, **ChatGPT Custom GPTs**, and **GitHub Copilot**.
